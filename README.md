## Project Description
This project is a **Kanban Board web application** developed as part of a DevOps course project.
It demonstrates the full DevOps lifecycle including:
- Containerization with Docker
- CI/CD pipeline
- Cloud deployment
- Documentation and quality practices

The application allows users to visualize tasks using a Kanban workflow (To Do, In Progress, Done).
